# Glossary and rules index (DESIGN-NOTES 9.3 and 9.4)

Status: **Approved sequencing 2026-11-25; compiled from approved text only.** Definitions restate DESIGN-NOTES and add no rules. Update this file whenever a rule changes. Terminology: "Blackbox" is the game, "BlackBox" is software, the contemporary era is "the Blackbox Protocol era" (9.1, 9.2).

## Part 1 — Glossary
| Term | Definition | Source |
|---|---|---|
| Adaptation milestone | A GM-approved demonstration of improved performance in an unfamiliar application of a skill; each removes 5 deficit points. | 5.1 |
| Alternative attribute | A justified different governing attribute for one task; adjustment floor(alt/2) − floor(default/2). | 3.1, R03 |
| Armor rating | 0–3 protection against the harm types it covers. | 4.2 |
| Assistance | Up to two helpers each +5 (total +10). | R02 |
| Attribute | One of STR, CON, DEX, INT, PER, WIL, PRE; creation total 350, range 15–80. | 1.1 |
| Blackbox Protocol era | The contemporary era (default year 2026). | 9.1 |
| Carry reference | STR × 0.5 kg; not a hard maximum. | 3.4 |
| CCDD | Career and Competency Development system. | CCDD-01 |
| CDR | Accumulated non-spendable development rating awarded on approved competency completion; determines additional concurrent learning slots, never individual competency eligibility. | CCDD-12 |
| Circumstance die | Optional D20 for an independent uncertainty. | R04 |
| Competency | A learnable named capability with levels I–V. | CCDD-02 |
| Critical failure / success | Natural 100 / natural 01. | R01–R06 |
| Deficit | Contextual penalty (0–25) for unfamiliar application after an era change. | 5.1–5.3 |
| Deprived / Severely deprived | Conditions from the shortage counter. | 7.3 |
| Difficulty ladder | +30 to −40 modifiers, the only difficulty scale. | R03 |
| Effective target | Final D100 target, clamped 1–99. | R01 |
| Era | Blackbox Protocol era, Signal Lost or Dead Zone. | F02.01 |
| Extended task | Progress-based task with target 3, 6 or 10. | R02 |
| Faction | An organization with goals, resources and territory, recorded per F23. | F23 |

| GM | The player who adjudicates the world. | F03 |
| Health (HP) | floor((STR+CON)/10), min 1; 0 means incapacitated. | 3.4, 4.3 |

| Indicator | One of twelve 0–6 world-state ratings. | F02.07, 8.1 |

| Skill | One of 30 general skills; base = half governing attribute. | 1.3 |
| Stamina | floor((CON+WIL)/2), spendable physical reserve. | 3.4 |
| Stress | 0–100 pressure record, separate from HP and stamina. | 4.4 |

## 2026-11-26 rule update
The former global CDR eligibility matrix is retired. Supporting-prerequisite equivalency is a GM-approved, evidence-backed waiver scoped to one prerequisite and target competency/level; it grants no level, CDR, hours, bonus or license. DESIGN-NOTES.md is authoritative.
