# Reusable inventory selection packages

Status: Proposed supporting content. Sources: F17, F07.8, EQUIPMENT-CATALOGUE.md. These are selection checklists, not free grants or guaranteed supplies. Select items individually according to campaign history, ownership, access, availability and resources. Quantity one is a suggested checklist default, not a prescribed consumption rate. Consumable quantities and package sizes must be recorded separately. No package price or mass is asserted while source values are TBR.
