# Blackbox Protocol System Reference Document
Version 0.1 — pre-release review draft. Not yet licensed for public reuse. Only this document's designated text is intended for CC BY 4.0 upon release; no other repository material is included. Numerical defaults remain subject to foundation reconciliation and playtesting.

## SRD-01 Resolution
The GM establishes intent, feasibility, stakes and applicable skill or raw attribute. Routine actions succeed without dice; impossible actions cannot be rolled. For uncertain possible actions roll D100 (1–100). Target is clamped to 1–99 after all distinct modifiers. Natural 1 critical success, natural 100 critical failure; otherwise roll <= floor(target/5) exceptional, <= floor(target/2) strong, <= target standard success, otherwise failure. Apply highest category. Opposed checks compare category then signed margin target minus roll; exact tie preserves status quo, both fail neither achieves intended action unless explicitly relative-only contest. Difficulty +30 very easy, +20 easy, +10 favorable, 0 standard, -10 challenging, -20 difficult, -30 severe, -40 extreme. Up to two materially contributing helpers +5 each. No duplicate modifiers. Example target60 with difficulty -20 and one helper becomes45; roll20 strong.
Retries require changed circumstances or meaningful declared cost. Optional push once on noncritical failed check when feasible, not irreversible or unchanged opposed check; declare extra risk, retain incurred consequences. Extended check progress targets 3/6/10; critical/exceptional/strong/standard add4/3/2/1, failure0, critical failure0 plus declared setback normally lose1 progress or equivalent cost. Each interval consumes time/resources; no double roll for same interval. Optional independent D20: 1–3 major complication,4–7 minor,8–17 neutral,18–20 opportunity; never automatically reverses primary result.

## SRD-02 Attributes and skills
STR strength, CON constitution, DEX dexterity, INT intelligence, PER perception, WIL willpower, PRE presence. Creation starts30 each, distribute140 additional points; reclaim down to15, maximum80, final total350. Underlying natural ceiling100. Effective attributes reflect distinct modifiers. Derived: HP max floor((STR+CON)/10), minimum1 living; stamina floor((CON+WIL)/2); resilience floor((WIL+CON)/2); initiative floor((DEX+PER)/2); movement floor((STR+DEX+CON)/3); reference load STR×0.5 kg; recovery floor((2CON+WIL)/3). Use effective attributes; capacity changes do not silently heal or refill.
General skill base floor(underlying governing attribute/2). Mapping:
- STR: Athletics.
- CON: Endurance, Survival.
- DEX: Close Combat, Firearms, Archery, Stealth, Vehicle Operation, Crafting.
- PER: Search, Surveillance, Streetwise, Navigation, Scavenging.
- INT: Forensics, Research, Electronics, Mechanics, Computing, Science, Communications, Medicine, Construction, Agriculture, Animal Husbandry, Resource Management.
- PRE: Persuasion, Intimidation, Leadership, Deception.
Skill target = underlying learned skill + floor(effective applicable attribute/2) − floor(underlying default governing attribute/2) + highest applicable competency bonus + difficulty + assistance + distinct modifiers − adaptation deficit. Clamp1–99. Raw checks use full effective attribute and distinct modifiers, not learned skill bonus.

## SRD-03 Character creation and advancement
Classless; no mandatory occupation or party role. Occupational skill pool100: primary100 with no secondary,80 with one,60 with two. Primary five allocations respectively 30/25/20/15/10,25/20/15/10/10,20/15/10/10/5. Secondary20 each distributed10/5/5. Combined occupational cap30 per skill; redistribute excess in increments5 among relevant skills. Personal skill pool100, max20 each; starting underlying skill ceiling85, advancement99. Custom history requires GM validation. Ownership, access, credentials and expertise separate. No duplicate kit from secondary background.
General advancement mark per meaningful scenario or distinct40 active hours; roll D100 above underlying skill, gain1D4 capped99; failed roll consumes mark. Attribute development eligible monthly with documented relevant development over at least30 in-world days; roll above underlying attribute, gain1 capped100. No double learning credit. Adaptation deficit0–25, largest applicable deficit only; distinct approved milestone removes5, normally8 active hours plus demonstration or equivalent field experience. No automatic advancement from elapsed time alone.

## SRD-04 Generic competencies
Levels0–5; complexity c=1–7. M(0)=0, M(L)=2^(L−1) for L>=1. Cumulative development value Q(L)=2^L−1. Bonus B(L)=5×max(0,L−1). Personal purchase from occupational level O to L costs c×(M(L)−M(O)); occupational grants require justified history and prerequisite closure, duplicate grants use highest level. Personal competency budgets10/15/20 by campaign starting environment (contemporary/crisis/reconstruction); unused expires. CDR=sum 100cQ(L) across unique competencies; never added to task target. Base active learning slots2/3/4 respectively; extra slots at CDR10000/25000/50000/100000/200000/400000. Retraining subset1/1/2. Incremental training hours H(c)×2^(L−1), H=[4,8,16,40,80,160,320]. Training requires access, prerequisites, practice, assessment and applicable CDR threshold; no self-funding threshold. Threshold matrix by complexity, levels I–V:
1:0,100,500,1500,3000
2:0,200,1000,3000,6000
3:0,500,2500,7500,15000
4:0,1000,5000,15000,30000
5:2500,5000,10000,30000,60000
6:5000,10000,25000,60000,120000
7:10000,25000,50000,120000,250000.
Active and assessment-pending projects occupy slots; pause retains hours and releases slot. Failed assessment retains hours, requires corrective practice. Advanced/Simulation efficiency discount min(30,10×floor(mean excess supporting prerequisite levels)) percent, snapshot at start; no discount if no supporting prerequisites or Standard; mandatory supervised/credential/assessment time nondiscountable; round adjusted eligible hours up, minimum1. No duplicate credit. Credentials and institutional authority separate.

## SRD-05 Time and encounters
One shared in-world clock; concurrent work does not multiply elapsed time, exclusive labor cannot overlap. Resolve due events and meaningful interruptions before advancing further. Six-second encounter round; initiative descending, ties higher effective PER then simultaneous GM adjudication. One main action, one movement allowance, one reaction; main may become second movement, no banking. Mobile movement max(1,floor(movement rating/5)) metres, immobile0. Abstract range engaged/near/far/out of reach; feasibility from fictional equipment. Aware defender may spend reaction on opposed DEX evasion or appropriate Close Combat defense; attacker must succeed and strictly win. Partial cover -10, substantial -20 when distinct, complete obstruction prevents direct attack. Abstract harm D4/D6/D8/D10 low/moderate/high/extreme; degree bonus0/1/2/3 standard/strong/exceptional/critical; protection0–3; penetrating loss max(0,die+bonus−protection). Noninjurious exertion affects stamina, no automatic HP conversion.

## SRD-06 Conditions
HP bounded0–maximum. Penetrating harm1 minor,2–3 moderate,4–6 severe,7+ critical. Highest directly relevant injury penalty0/-10/-20/-30 or infeasible; no duplicate attribute impairment. Zero HP incapacitated; severe/critical or ongoing life-threatening fictional condition unstable. Three deterioration boxes, one at end of subsequent round, death at three; no initial-round tick. Eligible Medicine stabilization success stops deterioration, critical failure adds box; no real medical guidance. Stable eligible recovery1 HP/day if recovery index<60 else2; qualified care strong or better adds1 once/day, cap3. Injury reassessment minimum eligible days1/3/7/14 by severity; not guaranteed cure. Quiet rest stamina floor(max/4), minimum1 per hour; adequate8h sleep restores remaining if eligible, no duplicate.
Stress0–100. Distinct pressure event intensity5/10/20, WIL check: strong+ adds0, standard floor(intensity/2), failure intensity, critical failure intensity+5. Thresholds strained max(1,ceil(resilience/2)), pressured max(1,resilience), overwhelmed max(1,min(100,resilience+25)); highest applicable penalty -5/-10/-20 only affected tasks. Player chooses response. Safe quiet hour reduces5, adequate8h sleep reduces20 instead, consensual successful support additional5 once/day; no acute-threat recovery. Persistent conditions require player/GM agreement.

## SRD-07 Generic world interfaces
Evidence record ID, source, time, provenance, status, visibility, links; essential clues multiple independent routes, obvious evidence not withheld by failed roll. Social state separates trust, reputation, affiliation, authority and obligations; no mind control. Inventory record ID, owner, location, quantity/unit, condition, access; atomic transfer, reservations not consumption, no negative stock. Market quote quantity×unit price, explicit fees, validate funds/stock; no universal exchange rate. Travel duration distance/declared feasible speed plus stops; hazards meaningful only. Resource balance opening+received+produced−consumed−lost−transferred. Project requires inputs, labor, elapsed minimum, tools, capacity, assessment; progress credited labor/required labor, completion requires all gates. Facility service capacity minimum of installed, staffing and input capacity; delivery min(demand,capacity). World events unique IDs, prerequisites, approved effects and history. These interfaces do not include proprietary item statistics, recipes, setting data or adventures.
