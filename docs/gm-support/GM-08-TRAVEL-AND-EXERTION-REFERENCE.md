# GM-08 — Travel and Exertion Reference
**Sources:** `notes/DESIGN-NOTES.md` F11, F19, §§3.4, 4.1, 7.3. **Status:** GM procedure and printable worksheet. Fixed strategic travel speed, fuel and exposure rates are **not approved/calibrated**; do not invent them.

## Travel resolution
| Step | GM decision |
|---|---|
| 1. Route | Origin, destination, distance, known/unknown route, alternative paths |
| 2. Access | Roads, bridges, permissions, terrain, infrastructure and era |
| 3. Conditions | Weather, shelter, exposure, load, transport condition |
| 4. Resources | Time, fuel, food, water, equipment, safe stops |
| 5. Hazard | Roll **only** when outcome is uncertain and consequential, using R01–R03 |
| 6. Consequence | Advance actual time; record spent resources, discovered information and changed access |

| Mode | Tracking |
|---|---|
| Standard | Narrative travel blocks, significant stops, shortages and hazards |
| Advanced | Route and supply plan, delays, condition changes |
| Simulation | Optional weather, load, maintenance and detailed ledger |

**Combat movement is not travel speed.** For a mobile character, movement index M=floor((STR+DEX+CON)/3), and level unobstructed **6-second** movement allowance is max(1,floor(M/5)) metres. Do **not** multiply this into an approved daily overland travel rate.
