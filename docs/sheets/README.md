# Character sheet and table trackers

Status: **draft layout (2026-11-25). Every field is taken from approved rules; no new mechanics.** Numbers are provisional until playtested, like the rules they come from. The layout and art direction are placeholders until the F29 visual identity is decided.

Files:
- `character-sheet.html`: three-page character record (US Letter).
- `trackers.html`: five table trackers (encounter, development projects, adaptation milestones, survival and supplies, extended tasks and projects).
- Generated by `tools/sheets/generate.py docs/sheets`. Edit the generator, not the HTML, then re-export the PDFs from a browser or with Playwright. **PDFs are not included until regenerated and print-verified against the current rules. Do not use the superseded 2026-11-25 PDFs.**

## Not included (not defined in the repo)
- Rules for grappling, chases, reloading, rapid fire, falling and poison (see the readiness audit).
- Travel speeds (F19 has no approved defaults), so there is no travel tracker.
- Final art, logos and family emblems (F29).
